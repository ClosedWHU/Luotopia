底部 **校园** 为子应用网格。长按图标可进入编辑：排序、隐藏、拖入文件夹；列数可在编辑工具栏中调整。

多数功能需要 [武大账户](/docs/user/accounts/#武大账户)；给分和评价还需要 [珞家账户](/docs/user/accounts/#珞家账户)。

## 子应用一览

| 给分和评价 | 搜索课程查看给分分布与评价 |
| 学习资料共享 | 尚未完成 |

学业状态等入口可能位于成绩页或其他位置。

## 空闲教室

**校园 → 空闲教室**：选择周次、星期、校区、楼栋后查询。点击节次可将该时段加入日程；若与已有课程冲突会提示确认。加入的事项会出现在主页与日程。

## 自习预约

**校园 → 自习预约**：登录武大账户后，选择空间、日期、时段与座位。用于图书馆座位预约，不是图书借阅或续借。

## 运动场馆

**校园 → 运动场馆**：选择场馆、项目与时段。预约与支付可能打开校内网页。完成后可将事项加入日程。

## E 卡与付款码

| 入口 | 说明 |
|------|------|
| 珞珈 E 卡 | 校园卡相关页面 |
| E 卡付款码 | 展示付款码；码会刷新。无效时请重新进入页面，或检查武大登录状态 |

> [!WARNING]
> 付款码会刷新，请勿使用过期截图；付款码无效时重新进入页面获取。

## 取水码、智慧珞珈、邮箱与消息

在校园网格中打开对应入口。智慧珞珈、邮箱、消息依赖有效的校内登录状态。

## 校园巴士（校巴）

有两种展示方式，**二选一**（不会同时显示卡片与网格图标）：

| 方式 | 说明 |
|------|------|
| **到站预览卡片** | 天气卡片下方显示实时到站（需定位权限；未登录时卡片仍可显示，数据可能受限） |
| **网格应用** | 普通「校园巴士」图标，点进完整页面 |

**编辑校园布局时**（长按图标进入编辑）：在天气/校巴卡片区域下方有 **「公交到站预览」** 开关。

- **开**：显示预览卡片，并隐藏网格中的校巴图标  
- **关**：隐藏卡片，网格中出现校巴图标  

该开关只表示偏好，与是否登录武大账户无关。关闭卡片后若仍看不到校巴图标，检查是否在编辑模式里把「校园巴士」隐藏了。

查看线路与位置依赖上游数据、网络与定位。

## 校历 · 全校课表 · 给分和评价

| 入口 | 说明 |
|------|------|
| **校园 → 校历** | 学期、假期与考试周 |
| **校园 → 全校课表** | 浏览全校开课（依赖服务端数据） |
| **校园 → 给分和评价** | 搜索课程查看历史给分与同学评价；「我的评价」在页内入口 |

提交评价的步骤：登录珞家 → 本机已有成绩并完成资格同步（见 [成绩与学业](/docs/user/scores/)）→ 搜索课程 → 撰写评价。不满足资格时，页面会说明原因。

## 校园网

**校园 → 校园网**（若已显示）：查询/管理校园网相关状态，依赖武大登录与上游系统。

**网费缴费** 子入口：查看余额、账户与当前套餐；选择充值金额（含自定义金额）；支持支付宝、微信支付与银联；提交前有二次确认弹窗，随后在收银台内完成支付。
