界面文案与法律文档以 App 内 **关于 / 法律** 页面为准。本文是操作向摘要。

## 存在本机的数据

| 类型 | 说明 |
|------|------|
| 课表、成绩、日程 | 默认本机；换机需导出/重导 |
| 武大教务会话 | 本机 Cookie / 会话，**不**上传珞家服务器 |
| 成绩资格同步 | 用户主动同步时，珞家服务器使用武大统一身份认证的一次性凭证核验成绩，私有保存修读记录，并将可匹配的数值成绩计入匿名聚合；不上传武大密码或教务 Cookie |
| AI 密钥与会话 | 本机；请求直达用户配置的第三方 |
| AI 校园工具调用（含就医服务与缴费） | 相关校园数据（检验/诊断/票据明细、订单号与金额）随请求发往你配置的第三方模型端点，并记录在本机操作日志；默认启用，无独立开关 |
| 开放网络访问 | 默认开启；网页正文作为不可信内容存于本机工作区，不进入对话 |
| VPN 账户密码 | 设备安全存储；勾选记住才持久化，除发往 VPN 服务器外不离开设备 |
| 缴费订单材料 | 本机临时保管，交付收银台后清除 |
| 热更新脚本缓存 | 本机；源文件来自官网，经签名校验 |

## 会发送到珞家服务器的数据

| 类型 | 说明 |
|------|------|
| 珞家登录 / 资料 / 会话 | 账户体系 |
| 论坛、课程评价等 | 需珞家登录 |
| 评价资格同步 | 课程标识等最小数据，**无**教务 Cookie |
| 设备推送 token（若启用） | 设备注册 |

## 会发往官网 / 第三方的

| 类型 | 说明 |
|------|------|
| 检查更新 | 官网 `releases` 接口 |
| 热更新清单与脚本 | 官网静态资源 |
| 天气 | 用户所选第三方天气 API |
| AI 模型端点 | 对话内容、工具调用涉及的校园数据 |
| VPN 服务器 | 校园 aTrust 认证与隧道流量 |
| 法律页 / 友情链接 | 官网静态 |

开发者选项中的自定义珞家服务器地址**不会**改变官网地址。水电费、网费等支付在校方或第三方支付网关的收银台内完成，珞家不经手资金。

## 遥测

分析、崩溃、性能等 **默认关闭**，可在设置隐私相关项中按需开启（以当前版本为准）。
