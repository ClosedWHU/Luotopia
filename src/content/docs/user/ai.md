底部 **AI** 提供对话功能。模型与密钥由用户自行配置，与是否登录珞家账户无关。

## 配置

打开 **设置 → AI 设置**，填写：

| 项 | 说明 |
|----|------|
| AI 提供商 | 内置常用服务商，或选择自定义 |
| API 格式 | 自定义时按服务商接口类型选择 |
| API 地址 | 服务商 Base URL |
| API 密钥 | 仅保存在本机，请妥善保管 |
| 模型 | 手动输入，或获取模型列表后选择 |
| 系统提示词 | 在「模型参数」区域展开后编辑，可选 |
| 助手 / 技能 / MCP | 管理入口在 AI 设置页，可配置助手、启用技能与添加 MCP 服务 |
| 开放网络访问 | 默认开启；关闭后联网搜索等工具从工具目录中消失。网页正文会作为不可信内容保存在工作区，不进入对话 |
| 联网搜索提供商 | tinyfish 为内置；bocha、brave、tavily 需自带 API 密钥 |

填写后可使用 **连接测试** 验证，再 **保存 AI 设置**。

## 使用

打开 **AI**，在输入框发送消息。顶部显示当前会话标题，支持新建、切换、重命名、置顶与删除会话。会话保存在本机，下次启动可恢复。右上角菜单还提供 **压缩上下文**、**图像生成** 与 **AI 朗读** 三项操作。

默认输入区只显示模型选择、附件、语音输入和发送操作。需要调整自动化级别、助手、技能或 MCP 时，展开输入区上方的高级控制；这些设置会影响后续请求。

支持图片、文件、语音识别和朗读；图片、文件与工具类入口会根据当前模型能力显示。执行校园数据操作时，AI 按三档区分确认：只读查询（如查看成绩、余额）一般直接执行；写入操作（如创建预约、加入日程）需你确认后才会继续；资金操作（如缴费下单）必须逐项单独确认。AI 也可能要求登录或人工验证；完成后可从结果卡片跳转到对应功能页面。

## AI 代缴费

可以让 AI 查询水电费、校园网费的欠费情况并下单缴费：

1. AI 下单后，对话中弹出确认卡片，由你选择支付渠道。  
2. 选定渠道后跳转到该功能自己的收银台（水电费为武汉大学安心付，网费为支付宝、微信支付或银联收银台）。  
3. 支付始终由你本人在收银台内完成，AI 不会代扣。  

> [!IMPORTANT]
> 资金操作不能批量同意。批量确认中包含缴费订单时，会提示「本批次包含资金操作，请逐项查看并分别确认」。

- 选择渠道后未付款直接退出，按未支付处理，且该订单不会再次提示；需要缴费时须重新发起。  
- 从收银台返回后，与学校系统核对结果最长约需 1 分钟。若出现「收银台已结束但尚未核验，请先查询订单 `{orderNo}`，不要重复付款」的提示，先查询订单与余额，不要重复下单，见 [常见问题](/docs/user/faq/)。

## 语音输入与朗读

语音设置入口在 **AI** 页右上角菜单的 **AI 朗读**（不在设置页）：

- 语音识别服务五种：speech_to_text（系统）、stts、Whisper 离线转写（需先下载模型）、OpenAI 实时转写、DashScope 实时转写（需 API 密钥；留空时若当前 AI 服务商兼容，会复用其密钥）。  
- 朗读引擎两种：Edge 在线音色、stts 系统音色。  
- 语音输入需要麦克风权限；未授权时无法使用，可在系统设置中开启。

## 故障排查

优先检查 API 地址、密钥、模型名称与网络连通性，而不是珞家登录状态。若设备无法访问所配置的 API，需自行调整网络环境。用量与计费以服务商账单为准。

AI 标签可在 **设置 → 通用 → 导航栏** 中显示或隐藏；与是否登录珞家无关。
