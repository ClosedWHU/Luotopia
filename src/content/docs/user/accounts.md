珞家使用两套独立账户，用途与登录入口不同。

| | 武大账户 | 珞家账户 |
|--|----------|------------------|
| 用途 | 导入课表与成绩、学业状态、自习预约、运动场馆、E 卡、邮箱、消息、校医院等校内服务 | 论坛、课程评价、登录会话与账户安全 |
| 入口 | **设置** 顶部「武大账户」；使用相关功能时也会要求登录 | **设置** 顶部「珞家账户」（未登录时显示「未登录」） |
| 是否发往珞家服务器 | 教务 Cookie / 密码 **不** 上传珞家服务器 | 是（登录与云端 API） |

## 武大账户

1. 打开 **设置 → 武大账户**。  
2. 按页面完成登录或绑定。  
3. 登录后可查看学院、专业、班级等信息，并可重新绑定或退出。

教务会话与凭证保存在本机，用于访问武大相关系统；武大密码不会提交给珞家服务器代管。E 卡、智慧珞珈等页面通过本机会话打开校内网页。

未登录武大账户时，课表导入、成绩、自习预约等功能不可用。

## 珞家账户

1. 打开 **设置 → 珞家账户**。
2. 登录：用户名或邮箱，以及密码。
3. 注册：用户名至少 3 个字符，密码至少 6 个字符；邮箱可选。可用邮箱域名由服务器配置决定，常见要求包含 `@whu.edu.cn`。
4. 若启用了验证码、二次验证或 Passkey，按页面提示完成。

登录后可管理资料、登录会话（包括将其他设备下线）、安全选项、API 凭证，以及退出登录。

### 其他账户（凭据中心）

除武大 / 珞家两套主账户外，**设置 → 其他账户** 汇总了多个校园服务的凭据。其中 7 种经 `features/account_center/` 凭据中心适配器聚合（武大 CAS、珞家、校内邮箱、VPN、知音、芒果、Ham）；其余入口（希冀、CS 易办、乐跑、超星学习通、电动车补录等）在同一页面由各自的 credentials store 展示，不属 account_center 适配器聚合。

| 凭据 | 用途 |
|------|------|
| 校内邮箱（coremail） | 邮箱登录 |
| VPN（aTrust） | 校园 VPN |
| 共享电单车（知音 / 芒果） | 电单车骑行 |
| Ham | 珞家社交登录源 |
| 超星学习通 | 课程、签到、视频 |
| 乐跑 | 步道乐跑 |
| 希冀平台 / CS 易办 | 实验课程平台 / 评奖评优 |

各凭据独立保存、按需登录；账户健康状态在入口统一展示。

## 与武大账户的关系

仅登录武大账户即可使用大部分校园功能。提交课程评价需要：已登录珞家账户，并使用武大统一身份认证的一次性凭证由珞家服务器核验对应课程的修读资格；本机教务 Cookie 不会上传。详见 [成绩与学业](/docs/user/scores/)、[给分和评价](/docs/user/campus/#校历--全校课表--给分和评价)。
