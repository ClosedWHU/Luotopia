## 课表或成绩无法导入

1. 确认 **设置 → 武大账户** 已登录。  
2. 确认网络可访问教务相关服务。  
3. 成绩导入若需要验证码，请完成验证后重试。  
4. 教务系统维护时，稍后再试。  
5. 仍失败时，退出武大账户后重新登录，再执行导入。  

## 付款码无效

重新进入 **E 卡付款码** 以刷新，不要使用旧截图。确认武大账户登录有效。若提供网页备用入口，可尝试使用。检查系统时间是否准确。

## 提醒未出现

在系统设置中允许珞家发送通知。Android 需开启对应通知渠道；准时提醒还需精确闹钟权限。水电费低余额提醒同样需要通知权限。确认事项已设置提醒且尚未过期。部分机型的省电策略会限制后台运行。

## AI 报错

在 **设置 → AI 设置** 中核对 API 地址、密钥与模型名称，并运行连接测试。确认设备网络可访问该 API；此问题与珞家登录无关。使用自定义提供商时，确认 API 格式选择正确。

语音相关问题排查：提示「未获得麦克风权限」时在系统设置中授权；使用 Whisper 离线转写前需先在 **AI 朗读** 面板下载模型；OpenAI / DashScope 实时转写需配置 API 密钥（或当前 AI 服务商密钥兼容复用）。

## AI 帮我缴费后不确定是否付成功

先等待约 1 分钟，应用会与学校系统核验支付结果。若提示「收银台已结束但尚未核验，请先查询订单 `{orderNo}`，不要重复付款」，到 **校园 → 水电费** 或 **校园 → 校园网 → 网费缴费** 查看余额与订单状态，不要再次下单。在选择渠道页直接返回按未支付处理，该订单不会再次提示，需要缴费时须重新发起。

> [!WARNING]
> 在确认订单状态前，请勿重复下单或重复付款，以免造成重复扣费。

## 就医服务里缴费记录、挂号记录或未缴费账单打不开或为空

这些内容依赖云端医疗解析脚本：到 **设置 → 热更新** 下拉更新脚本后重试，并确认武大账户登录有效。

## 更换设备后数据缺失

课表、成绩与日程默认保存在本机。课表可在旧设备导出珞家 JSON，在新设备通过本地文件导入。成绩需重新导入。日程目前没有可靠的云端备份。论坛等云端内容可使用同一珞家账户登录后访问。

## 密码是否会上传

| 类型 | 说明 |
|------|------|
| 武大 | 会话保存在本机，用于访问教务与校内服务；不是将密码交由珞家服务器代管 |
| 珞家 | 密码仅发送至珞家登录接口 |
| AI 密钥 | 仅发送至用户配置的第三方 AI 服务 |

两套账户相互独立。

## 论坛或课程评价无法使用

1. 确认已登录 **珞家账户**。
2. 论坛默认在导航中 **隐藏**：到 **设置 → 通用 → 导航栏** 打开「论坛」标签。
3. 课程评价还需要成绩修读资格，见 [成绩与学业](/docs/user/scores/)。
4. 若修改过服务器地址，请在开发者设置中确认后端可访问。

## 图书借阅入口

校园中有 **图书借阅** 入口，用于借阅记录与到期提醒。图书馆座位预约请使用 **自习预约**。

## 主页没有内容

确认是否已导入课程表（[课程表](/docs/user/timetable/)），以及是否有日程事项（[日程与事项](/docs/user/schedule/)）。检查 **主页设置** 中的显示范围与透明度。壁纸对比度不合适时可在外观中更换。

## 检查更新失败

1. 确认设备能访问官网（`www.whu.sb`）。  
2. **设置 → 关于 → 检查更新**。列表项右侧会显示加载状态。  
3. 若当前仅发布了测试版，默认会检查测试版；若在开发者选项中关闭了「接收测试版更新」，且暂无正式版，会提示无法检查。  
4. 更新包信息来自官网发布接口，不是珞家服务器。  
5. macOS / Windows 上安装被系统拦截（未签名、Apple 芯片要求等），见官网下载页说明。

## 热更新列表一直加载或显示本地缺失

热更新用于拉取校园/教务 **解析脚本**（不是整包 APK）。

1. 打开热更新页，下拉刷新。  
2. 「本地缺失 · 云端 vN」表示尚未下载该脚本，下拉即可拉取。  
3. 失败时仍可使用 App 内置解析；仅新能力可能依赖云端脚本。  
4. 与「检查更新」安装包无关。

## 校园页看不到校巴 / 开关无效

见 [校园服务 · 校园巴士](/docs/user/campus/#校园巴士校巴)：预览卡片与网格图标互斥；编辑模式下在卡片下方切换「公交到站预览」。

## VPN 连不上 / 提示需要权限

先区分代理方式：

| 方式 | 说明 |
|------|------|
| 应用内代理 | 仅本应用的流量走 VPN，无需额外权限 |
| 系统级代理（实验性） | 接管系统全部流量，需按平台授予权限（见下） |

系统级代理的权限要求：

- Android/iOS：授予系统 VPN 权限，可在首次引导、连接时的系统弹窗或系统设置中完成。
- Windows：虚拟网卡需以管理员身份运行并放置 wintun.dll；系统代理本身不需要管理员。
- macOS：只通过系统 HTTP 代理接管，无虚拟网卡；修改系统代理时需要输入管理员密码。

若服务器发起短信或动态令牌（TOTP）二次认证，提示「本次验证已结束」说明挑战已过期，需重新连接获取新的验证码。VPN 账户密码保存在设备安全存储中，除发送至 VPN 服务器外不会离开本设备。
