底部 **设置**。页面顶部为 **珞家账户** 与 **武大账户**，说明见 [账户](/docs/user/accounts/)。

## 通用设置

包括语言、**导航栏**、通知等，以及清除缓存。清除缓存通常不影响课表与账户数据，以页面提示为准。

### 导航栏

见 [开始使用 · 主导航](/docs/user/getting-started/#主导航)。可隐藏论坛、调整顺序，并将冷启动页设为第一个可见标签。

## 外观与壁纸

主题明暗与配色在 **外观**；壁纸可按页面分别配置（主页、校园、设置、日程、论坛、AI 等），来源包括无、本地图片、Bing 每日图等。

## 主页 / 时间网格 / 课表提醒

- **主页设置**、**时间网格**、**课表分组**、**课表提醒** 等：控制主页格子、多课表、上课提醒等（以当前版本菜单为准）。  
- 可配置时间块、起始时间、格子高度、午休、透明度、宽屏范围等。

## 通知

系统支持时，可在 **通知** 中管理渠道与相关权限提示。

## 隐私

与本地数据、可选遥测（分析 / 崩溃 / 性能，默认关闭）等相关选项，以页面说明为准。

## AI

见 [AI](/docs/user/ai/)。

## 天气

校园页等位置展示天气，由客户端直连第三方。可配置提供商（OpenMeteo、小米、AccuWeather 等）、定位方式、更新间隔、AQI 标准；部分提供商需 API 密钥。

## 桌面小组件

将课表样式同步到系统桌面小组件。支持时可通过页面添加，或按「如何添加」说明操作。

## 友情链接

有配置时显示，用于打开相关网站与项目链接（数据来自官网静态 JSON）。

## 热更新

**设置 → 热更新**：管理教务/校园**解析脚本**的本地与云端版本。下拉可检查并下载；「本地缺失」表示尚未缓存，下拉即可拉取。与安装包检查更新不是同一功能。

## 关于

显示版本号、简介、法律文档与开源许可。

- **检查更新**：官网发布接口（背后聚合官网发布页，安装包）。默认会检查测试版；可在开发者选项关闭「接收测试版更新」。Android 会在应用内下载，其他平台打开发布页由系统完成安装。  
- 连续点击 **版本号** 开启开发者模式。

## 开发者设置

仅在开发者模式开启后出现，常见项：

| 项 | 说明 |
|----|------|
| 自定义服务器 | 联调珞家后端（Auth / 业务 API） |
| 接收测试版更新 | 关闭后仅检查正式版；无正式版可用时，检查更新会显示已是最新或无法检查 |
| WebView 调试等 | 开发排查用 |

联调地址示例：

- Android 模拟器：`http://10.0.2.2:6262`  
- 真机：`http://电脑局域网IP:6262`  

日常使用保持默认即可。
