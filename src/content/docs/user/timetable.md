## 在主页查看

打开 **主页**。课程与事项显示在时间网格上。通过顶栏箭头或滑动切换日期/周次；点击条目查看详情；在空白区域长按可新建事项（起止时间按格子预填）。

时间块数量、是否隐藏午休、透明度等在 **设置 → 主页 / 时间网格** 相关项中配置；壁纸在 **设置 → 外观 / 壁纸**。

## 课表管理

**校园 → 课程表** 中可以：

- 查看已有课表（名称、学期与来源）  
- 添加课表，或创建空白课表  
- 对指定课表：重命名、编辑课程、更新、导出、拆分、删除  

## 从教务 / 研究生系统导入

导入页按账户类型提供两个互斥入口：

- **武汉大学教务系统**（jwgl，本科生）
- **武汉大学研究生系统**（newyjs，硕博研究生）

操作：登录 [武大账户](/docs/user/accounts/#武大账户) → 打开 **校园 → 课程表** → 选择对应系统的导入入口 → 按流程完成验证 → 返回主页核对课程。

主页无内容时的提示也会引导至导入流程。若导入解析异常，可到 **设置 → 热更新** 下拉更新解析脚本后再试。

## 其他导入方式

导入页还可能提供：

- 本地文件（珞家 JSON 备份）  
- WakeUp 等格式  
- 第三方课表 / 分享口令（名称以界面为准）  

具体选项以当前版本界面为准。

## 手动编辑

在 **校园 → 课程表** 中选择课表，进入 **编辑课程**，修改节次、地点、教师等。也可从主页打开课程详情后编辑。

## 多课表

可保存多张课表（例如不同学期，或混合课表）。更新按来源重新拉取，不支持更新的来源会提示；拆分将混合课表按来源拆成独立课表。

> [!CAUTION]
> **删除** 会移除该课表中的课程，请确认后再操作。

## 导出

在课表管理中选择 **导出课程表**。常见格式包括：

- 标准日历（.ics）：供外部日历应用订阅 / 导入  
- 珞家 JSON：完整备份，便于在本应用中再次导入  
- WakeUp CSV / 分享文件  
- 时光、Starlink JSON  

空白课表无需导出。更换设备时，建议先导出 JSON，再在新设备上导入。
