## 首次启动

首次打开会进入引导流程：

1. 选择语言  
2. 阅读并同意用户协议与隐私政策  
3. 按需授予通知、精确闹钟、定位、桌面小组件、相册、VPN、麦克风、相机等权限（可稍后在系统设置中开启）。其中 VPN 为系统级授权（Android 会弹出系统同意框，iOS 需安装 VPN 配置），用于 **校园 → VPN** 连接 aTrust；麦克风用于 AI 语音输入；相机用于拍照加入 AI 附件  
4. 可选登录武大账户；跳过后可在 **设置 → 武大账户** 再登录  

协议更新后，可能需要再次确认才能进入主界面。

## 主导航

底部（或宽屏侧栏）标签可自定义。**默认**大致如下：

| 标签 | 功能 | 默认 |
|------|------|------|
| 主页 | 课表时间网格，展示课程与日程事项 | 显示 |
| 日程 | 事项列表 | 显示 |
| 论坛 | 社区 | **隐藏**（可在导航设置中打开） |
| AI | 对话；需先在设置中配置模型与密钥 | 显示 |
| 校园 | 课程表、成绩、自习预约、E 卡、校巴等 | 显示 |
| 设置 | 账户、外观、主页、天气、更新等 | 始终显示，且固定在最后 |

在 **设置 → 通用设置 → 导航栏设置** 可：

- 调整标签 **显示 / 隐藏** 与 **排序**（设置不可隐藏）  
- 设置标签文字模式（选中时 / 全部 / 不显示）  
- **第一个可见标签** 为冷启动进入的页面  

## 主页无内容

本机尚无课表与事项时，主页会提示导入课表或新建事项。可从 **校园 → 课程表** 导入，或在主页空白区域长按新建。

## 数据存储

- 课表、成绩、日程：默认保存在本机。更换设备需重新导入；课表支持导出备份，见 [课程表](/docs/user/timetable/)。  
- 论坛、课程评价等云端功能：依赖珞家账户，与武大教务会话相互独立。  
- 天气：由客户端直接请求第三方服务，不经过珞家服务器。  
- 安装包更新与解析脚本热更新：来自官网（`www.whu.sb`），见 [设置](/docs/user/settings/)。
