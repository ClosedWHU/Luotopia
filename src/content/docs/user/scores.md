## 成绩

入口：**校园 → 成绩**（页面标题为「成绩查询」）。

### 导入

先登录 [武大账户](/docs/user/accounts/#武大账户)，再进入 **成绩导入**。可选方式：

| 方式 | 说明 |
|------|------|
| 本科教务 | 成绩较完整；更新可能较慢；可能需要验证码 |
| 可信电子凭证 | 下载官方中文成绩单（本科生主修 / 辅修）并在本机解析 |
| 专业发展指导系统 | 多为绩点信息，更新往往更早，明细通常不如教务完整 |

> [!NOTE]
> 上述成绩导入渠道目前面向**本科生**系统；研究生账户（硕士 / 博士）暂无可用的成绩导入渠道。研究生身份可用于登录、课表导入与学籍资料（见 [课程表](/docs/user/timetable/)）。

成绩保存在本机，用于查看与 GPA 计算。

### 浏览与 GPA

成绩按学期分组。可查看分数段分布、挂科标记，以及总 GPA、总学分。

在成绩相关设置中可切换 **GPA 计算标准**（如武大 2021+、WES、标准 4.0、百分制均分），切换后会重新计算汇总。

### 隐私锁

开启 **生物识别锁** 后，成绩单先显示「已被隐私锁保护」，点击后通过 Face ID 或指纹解锁。适用于不希望成绩立即可见的情况。

### 同步（课程评价资格）

在 **给分和评价** 提交课程评价前，需要同步已完成课程。App 会取得武大统一身份认证的一次性凭证和成绩验证码并交给珞家服务器；珞家服务器使用该凭证直接向武大教务核验成绩及账户归属，不上传或保存本机教务 Cookie：

1. 登录 [珞家账户](/docs/user/accounts/#珞家账户)。
2. 在给分和评价的课程详情页执行资格同步。
3. 同步后的成绩明细作为私有记录保存，修读结果用于评价资格判定；同步流程也会将可匹配的数值成绩计入匿名聚合。

公开页面达到至少 5 名独立贡献者的隐私阈值后才展示珞家聚合结果。Ham（武汉大学另一款校园应用）的数据由珞家服务器作为独立数据源查询，不由 App 上传。

导入或解析失败时，可检查武大登录，并在 **设置 → 热更新** 更新相关解析脚本。

## 学业状态

可从成绩页中的学业状态入口，或校园中的其他入口进入。需要武大账户登录，用于查看培养方案与修读进度。上游系统异常时可稍后重试。
