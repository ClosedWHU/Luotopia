核对日期：**2026-11-27**。首页在截图与下载 CTA 之间呈现 35 项、4 组对比。
这是一份路径级别的功能覆盖对照，不是跑分、稳定性评测，也不是所有身份权限下的完整产品规格。

使用已登录学生角色查看门户与目录；没有提交申请、预约、支付、审批或变更个人信息，没有运行 APK。本文仅记录功能名与公共入口，不保存用户、课表、待办、Cookie、SSO 跳转参数等私有数据。

## 判定与维护规则

- **原生 / 原生＋网页**：存在对应客户端界面；不是“无需联网”或“完整流程全原生”的承诺。
- **网页 / WebView**：已确认路径为网页；复杂官方流程在珞家内的网页入口也必须如实计入。
- **部分支持**：聚合功能中只有部分流程原生整合，或仍需跳转补齐，附单元格解释。不要将其解读为服务故障。
- **不支持**：有明确否定依据；目前用于珞家未交付的独立 Web 客户端，不基于抓取失败或未找到代码来否定竞品。
- **未核实**：证据不足；保持中性，不并入“不支持”。

数据唯一入口为 `src/config/comparison.ts`，结构化键使用 `TranslationKey` 约束；组件为 `src/components/FeatureComparison.astro`。既有功能名复用功能字典，比较文案使用 `comparison.*`，必须同步所有已发布语言。

新增或修改评分时同步此文档的来源、日期与边界。不把登录态页面快照、下载的 APK、第三方脚本、个人数据或内部接口细节提交到仓库。执行 i18n 校验、生产构建、产物 i18n 校验，并在实际浏览器检查展开/折叠、键盘、明暗主题与窄屏换行。
