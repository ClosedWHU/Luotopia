# 首页功能对比：范围、依据与维护

## 比较范围

核对日期：2026-11-27。首页比较常用服务的访问方式和设备支持，依据下列客户端版本及学生账号可见的门户目录。

- 珞家优势：日常高频查询、课表、付款码、邮箱等有独立客户端界面，并整合桌面、小组件、手表与自动化。
- 珞家边界：复杂行政业务仍依赖内嵌官方门户；体育预约、医疗和水电支付存在网页步骤；独立 Web 客户端尚未发布。源码实现也可能受到版本、平台和云端开关限制。
- 智慧珞珈优势：官方目录和办事大厅覆盖较广，包含角色相关的教学、行政、财务、科研等正式流程，且有浏览器入口。
- 智慧珞珈访问方式：已核对的门户业务使用网页；安装包另含原生模块。网页标记仅描述已确认的入口，其他访问方式尚未核实。

使用已登录学生角色查看门户与目录；没有提交申请、预约、支付、审批或变更个人信息，没有运行 APK。本文仅记录功能名与公共入口，不保存用户、课表、待办、Cookie、SSO 跳转参数等私有数据。

## 判定与维护规则

- **原生**：已确认的访问方式为客户端原生界面，使用实心圆勾。完整原生客户端另有可选网页入口时仍标为原生，例如 Coremail 邮箱。
- **网页**：已确认的访问方式为网页，包括珞家内嵌的官方门户。
- **部分原生**：部分步骤使用原生界面，部分步骤使用网页，使用空心圆勾。例如体育预约、医疗、水电、E 卡、校园网和消息/待办。此状态描述原生化程度，功能覆盖须按具体业务核对。
- **不支持**：有明确否定依据，包括未发布的珞家 Web 客户端及维护者核实的智慧珞珈缺失能力。
- **部分支持**：仅支持本行的一部分能力，须写明支持范围；当前用于智慧珞珈仅提供中英文的多语言能力，与“部分原生”的界面方式区分。

状态描述访问方式，不评价办结成功率或体验优劣。浏览器版一行比较两款产品的浏览器入口：珞家 Web 客户端和智慧珞珈网页门户。

数据唯一入口为 `src/config/comparison.ts`，结构化键使用 `TranslationKey` 约束；组件为 `src/components/FeatureComparison.astro`。既有功能名复用功能字典，比较文案使用 `comparison.*`，必须同步所有已发布语言。

新增或修改评分时同步此文档的来源、日期与边界。不把登录态页面快照、下载的 APK、第三方脚本、个人数据或内部接口细节提交到仓库。执行 i18n 校验、生产构建、产物 i18n 校验，并在实际浏览器检查展开/折叠、键盘、明暗主题与窄屏换行。
