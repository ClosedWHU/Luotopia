## 説明 *
Luotopia（珞家）は、武漢大学の学生・教職員のためのワンストップ・デジタルキャンパスクライアントです。授業・学業、キャンパスサービス、スマートツールを一つの洗練されたデスクトップアプリにまとめました。

【授業と学業】
時間割は教務システム・大学院システムなど複数ソースからのインポートと複数時間割の管理に対応し、週・月表示と授業リマインダーを備えます。予定とToDoで授業・スケジュール・タスク・メモ・服薬を一括管理（繰り返しと通知対応）。空き教室検索は自分の時間割との衝突を自動で除外。図書館の自習席予約、図書の貸出・更新、スポーツ施設の予約。全学の時間割を閲覧して、自分の時間割と衝突しない聴講可能な授業を検索できます。成績は複数チャネルからのインポート、GPA 計算と成績推移に対応。学業状況、学事暦、成績分布と匿名の授業レビューに加え、コーススペース、専攻・プログラム情報、CS易办（コンピューター科学学院の手続きプラットフォーム）も搭載。

【キャンパスサービス】
珞珈Eカードの支払いコード自動更新。スクールバスのリアルタイム位置・路線検索・到着通知。ネイティブのキャンパスマップ（場所検索と施設レイヤー）。診療の受付・順番・領収書・検査結果の照会。寮の水道光熱費の支払いと給湯コード。キャンパス通知の集約。智慧珞珈ポータルへの直接アクセス。キャンパスネットワークのプラン管理。Sangfor aTrust キャンパス VPN。コミュニティフォーラム「珞珈防空洞」。さらにキャンパスニュース、食堂、シェア電動自転車、楽跑（Lepao）ランニング、洗濯、イベントチケット争奪、プロフィールとダイレクトメッセージを備えたコミュニティソーシャルにも対応します。

【ヘルスケア】
服薬は予定と連動したスケジュールで服用量・在庫を管理。スコア付きの心理自己評価尺度をライブラリとして収録。端末内で処理されるプライベートな生理日トラッカー（周期予測付き）。

【スマートツール】
マルチモーダル AI アシスタントを内蔵し、会話でキャンパスサービス的操作を実行できます。複数ソースの天気・AQI・降水アラート。Coremail キャンパスメールの送受信と未読バッジ。壁紙センター（ローカル・オンライン・Bing デイリー）。署名付きホットアップデートスクリプトにより、キャンパス API の変化へも新バージョンなしで素早く対応します。

【セキュリティとプライバシー】
CAS シングルサインオン、珞家アカウント、Passkeys に対応。デバイストラストとトークンバインディングで認証情報のリプレイを防止。すべての認証情報は端末上で暗号化保存。統計とクラッシュレポートは完全に任意で、既定ではオフです。ダークモード、11 言語（12 の表記バリエーション）、武大アカウントごとに分離されたマルチアカウント切り替えに対応。

Luotopia エコシステムは Windows、macOS、Linux、Android、iOS、HarmonyOS をカバーし、スマホ・デスクトップ・ウォッチの体験を同期します（ウィジェットやウォッチ連携はモバイルのみ）。

Luotopia は ClosedWHU チームにより独立開発されたサードパーティ製クライアントであり、武漢大学の公式アプリではありません。すべてのキャンパス機能は本人のキャンパスアカウント認証情報を必要とします。
